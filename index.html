Eenmalige Firebase setup
🔥 Connect your Firebase project
Firebase is a free Google service. Your family's data lives in your own account — nobody else can access it.
1
Go to console.firebase.google.com and create a new project (e.g. ToolTrak). Disable Google Analytics if asked.
2
In the left menu click Build → Firestore Database → Create database → choose Start in test mode → pick any location → Done.
3
Click the ⚙️ gear icon → Project settings → scroll to "Your apps" → click the </> Web icon → give it a name → Register app.
4
You'll see a firebaseConfig block. Copy each value and paste below.
💡 Share the same config with every family member — paste it once on each phone. After that, everyone's changes sync instantly in real time.
