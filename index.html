🔥 Verbind je Firebase-project
Firebase is een gratis Google-dienst. Jouw familiedata staat in jouw eigen account — niemand anders heeft toegang.
1
Ga naar console.firebase.google.com en maak een nieuw project aan (bijv. WieBewaartWat).
2
Ga naar Build → Firestore Database → Maak database → kies Testmodus → kies een locatie → Gereed.
3
Klik op ⚙️ → Projectinstellingen → scroll naar "Jouw apps" → klik </> → geef naam → App registreren.
4
Kopieer de waarden uit het firebaseConfig blok en plak ze hieronder.
💡 Deel dezelfde config met elk familielid — eenmalig invoeren per telefoon. Daarna synchroniseert alles direct.
